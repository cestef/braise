**Input Module**

Provides input handling utilities.

**Functions:**

- `text(prompt)` - Get text input from user
- `num(prompt)` - Get numeric input from user
- `confirm(prompt)` - Get confirmation (yes/no) from user
- `select(prompt, options)` - Get selection from user
- `multiselect(prompt, options)` - Get multiple selections from user
- `password(prompt)` - Get password input from user
