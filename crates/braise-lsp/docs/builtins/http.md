**HTTP Module**

Provides HTTP client functionality for making web requests.

**Functions:**

- `get(url)` - Make a GET request to the specified URL and return the response body as a string
- `post(url, body)` - Make a POST request to the specified URL with the given body and return the response body as a string
- `put(url, body)` - Make a PUT request to the specified URL with the given body and return the response body as a string
